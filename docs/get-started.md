# Getting Started

Singulary is a self-hosted AI app builder. Getting started is easy and can be done entirely locally.

## First Run
1. **Setup wizard** — Open the UI at `http://localhost:3000` (or your domain) and create the first admin user.
2. **Provider keys** — Navigate to **Admin → Providers** and add an OpenAI-compatible endpoint (or **Provider Keys** for personal BYOK).
3. **Docker** — Go to **Admin → Docker** to configure Docker access (socket or remote daemon). Click *Check connection*.
4. **Workspace** — Create a workspace from your dashboard.
5. **Project** — Add a project (Node, Bun, Python, Go, Rust, PHP, or static) from a template.
6. **Chat** — Open the project, switch to the agent panel, pick an LLM model, and start building.
7. **Preview** — Once the dev server is running, the preview tab will auto-detect the port and display your app.
